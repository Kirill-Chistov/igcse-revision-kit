# The Periodic Table — Summary

Specification points 1.18–1.24 · Topic 1 Principles of chemistry.

## Essential facts

- Order of increasing **atomic number**; columns = **groups**, rows = **periods**.
- Shells fill 2, 8, 8, 2. **Period** = number of shells; **group** = outer electrons (Group 0 =
  full outer shell). e.g. S (Period 3, Group 6) = 2.8.6; Ca = 2.8.8.2.
- **Metals**: left of the stepped line; conduct electricity; **basic** oxides (alkaline solution if
  soluble). **Non-metals**: right of the line + hydrogen; do not conduct (except graphite);
  **acidic** oxides.
- Same group → same number of outer electrons → similar chemical properties.
- Noble gases: full outer shell → stable → no tendency to lose, gain or share electrons →
  unreactive.

## Common traps

- Group 0 does not mean zero outer electrons.
- Same number of shells = same **period**, not same group.

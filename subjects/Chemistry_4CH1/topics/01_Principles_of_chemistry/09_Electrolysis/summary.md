# Electrolysis — Summary

Specification points 1.55C–1.60C · Topic 1 Principles of chemistry. **All Paper 2 only.**

## Essential facts

- Current = moving charged particles. Covalent compounds: neutral molecules → no conduction.
  Ionic: conduct only molten or aqueous (ions free to move; fixed in the solid).
- **Cation** (+) → **cathode** (−). **Anion** (−) → **anode** (+). Inert electrodes: graphite /
  platinum.
- **Cathode**: gain of electrons = **reduction**. **Anode**: loss of electrons = **oxidation**.
- Molten compound: metal at cathode, non-metal at anode.
- Aqueous: cathode → metal if less reactive than H, else **H₂**; anode → **halogen** if halide
  present, else **O₂**.

## Half-equations

```
Pb²⁺ + 2e⁻ → Pb            2Br⁻ → Br₂ + 2e⁻          molten PbBr₂
2H⁺ + 2e⁻ → H₂             2Cl⁻ → Cl₂ + 2e⁻          NaCl(aq)  (solution → NaOH)
2H⁺ + 2e⁻ → H₂             4OH⁻ → O₂ + 2H₂O + 4e⁻    dilute H₂SO₄  (H₂ : O₂ = 2 : 1)
Cu²⁺ + 2e⁻ → Cu            4OH⁻ → O₂ + 2H₂O + 4e⁻    CuSO₄(aq)  (blue fades)
```

## Practical and gas tests

- Inverted test tubes of solution over graphite electrodes, low-voltage d.c.
- H₂: squeaky pop with lighted splint. O₂: relights glowing splint. Cl₂: bleaches damp litmus.

## Common traps

- NaCl(aq) gives hydrogen, not sodium. Anode electrons go on the right.

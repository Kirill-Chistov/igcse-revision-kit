# Level of organisation — Summary

**Specification point 2.1** · Papers 1 and 2

organelle → cell → tissue → organ → organ system

| Level | Made of | Example (animal / plant) |
| --- | --- | --- |
| Organelle | structure inside a cell | mitochondrion / chloroplast |
| Cell | organelles | muscle cell / palisade cell |
| Tissue | similar cells, one function | muscle tissue / palisade tissue |
| Organ | several different tissues | stomach / leaf |
| Organ system | several organs | digestive system / shoot system |

Trap: tissue = one kind of cell; organ = several tissues.

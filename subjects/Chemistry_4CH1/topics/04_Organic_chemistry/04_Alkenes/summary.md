# Alkenes — Summary

Specification points 4.23–4.28 · Topic 4 Organic chemistry.

## Essential facts

- Functional group **>C=C<**; general formula **CₙH₂ₙ**.
- **Unsaturated**: contains a C=C double bond, so atoms can be added.
- Ethene CH₂=CH₂ · propene CH₂=CHCH₃ · but-1-ene CH₂=CHCH₂CH₃ · but-2-ene CH₃CH=CHCH₃. The number
  is the position of the C=C.
- Addition of bromine: C₂H₄ + Br₂ → C₂H₄Br₂ (1,2-dibromoethane); one Br on each C of the old C=C.
- Test: shake with bromine water. Alkene: **orange → colourless**. Alkane: **stays orange**.

## Common traps

- Say "colourless", not "clear".
- Addition gives one product; no HBr.

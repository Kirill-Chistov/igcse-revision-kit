# Cloning — Summary

**Specification points 5.17B–5.20B** · all Paper 2 only

- **Micropropagation**: explants from shoot tips of a parent with desired characteristics →
  sterilised → in vitro on sterile agar with nutrients + plant hormones → mitosis → plantlets →
  compost. All genetically identical.
- **Commercially**: huge numbers fast, all with desired characteristics, all year, small space,
  disease-free. Drawback: no variation.
- **Dolly**: diploid nucleus from sheep A's udder cell → into sheep B's enucleated egg → electric
  shock → embryo (mitosis) → surrogate sheep C → lamb identical to sheep A.
- **Cloned transgenic animals**: human gene into sheep/goat cell → clone it → herd all make the human
  protein in milk → extract and purify. Cloning because every clone keeps the gene; sexual
  reproduction would lose it in some offspring.

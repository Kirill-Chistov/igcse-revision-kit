# Text, sound and images — Summary

| Field | Value |
| --- | --- |
| Specification points | 1.2.1–1.2.3 |
| Paper | Paper 1 |

## Text

- Text is converted to binary using a **character set**: each character has a unique binary code.
- **ASCII:** 7 bits (8 extended), 128 characters, English only. A = 65, a = 97, in sequence.
- **Unicode:** more bits per character (up to 32), far more characters — **other languages and
  emojis** — but **larger** text files.

## Sound

- Analogue wave **sampled**: amplitude measured at regular intervals, each stored in binary.
- **Sample rate** = samples per second (Hz). **Sample resolution** = bits per sample.
- Increase either → **more accurate recording** and **larger file**.

## Images

- Image = grid of **pixels**; each pixel's colour stored as a binary code.
- **Resolution** = number of pixels. **Colour depth** = bits per colour; *n* bits → 2ⁿ colours.
- Increase either → **better quality** and **larger file**.

## Traps

- Sample **rate** ≠ sample **resolution**.
- Colour depth is **bits**, not number of colours.

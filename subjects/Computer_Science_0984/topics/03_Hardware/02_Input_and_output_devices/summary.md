## Essentials

- **Input device**: converts outside data into a form the computer can process.
- **Output device**: converts processed data into something seen, heard, printed or a physical action.
- **Sensor**: input device measuring a physical property; lets a computer monitor/control
  automatically, continuously, accurately, in dangerous places.
- **Actuator**: output device turning a signal into movement (motor, valve).

## Input devices — one line each

- Barcode: light reflected from bars/spaces → number. QR: camera image of 2D grid → decoded, more data.
- Camera: lens → sensor of pixels. Keyboard: key completes circuit → character code.
- Microphone: diaphragm vibrates → electrical signal → digital. Optical mouse: LED + camera compares images.
- 2D scanner: light across flat page → image. 3D scanner: many angles → 3D model.
- Touch: **resistive** = layers pressed together (any stylus, cheap); **capacitive** = finger changes
  electrostatic field (multi-touch, clear); **infra-red** = broken grid of IR beams (gloves, large screens).

## Output devices — one line each

- LCD screen: crystals block/let through backlight. LED screen: LEDs are the pixels, no backlight.
- DLP projector: tilting micro-mirrors. LCD projector: light split into RGB, three LCD panels, prism.
- Speaker: signal → coil → cone vibrates. Inkjet: droplets from moving head, line by line.
- Laser: charged drum, laser image, toner, paper, fuser. 3D: object built layer by layer.

## Sensors

acoustic (sound) · accelerometer (acceleration/tilt) · flow (rate of flow) · gas · humidity (vapour
in air) · infra-red (heat / broken beam) · level (how full) · light · magnetic field · moisture
(water in soil) · pH · pressure (weight/contact) · proximity (near, no contact) · temperature.

## Traps

- Humidity ≠ moisture; level ≠ flow; proximity ≠ pressure.
- The microprocessor decides, not the sensor.

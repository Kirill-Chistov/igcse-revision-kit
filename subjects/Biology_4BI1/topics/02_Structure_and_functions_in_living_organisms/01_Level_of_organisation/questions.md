# Level of organisation — Questions

**Specification point 2.1** · Papers 1 and 2

Marking guidance below is written for this repository; it is not an official mark scheme.

## Questions

1. Put these in order from smallest to largest: organ, cell, organ system, organelle, tissue.
2. Define *tissue*.
3. Define *organ*, and name one organ found in a plant.
4. Classify each as organelle, cell, tissue, organ or organ system: (a) heart, (b) ribosome,
   (c) red blood cell, (d) xylem, (e) circulatory system.
5. **[3 marks]** *Describe* how the digestive system shows the levels of organisation, using the
   stomach as your example.

## Answers and marking guidance

1. organelle, cell, tissue, organ, organ system.
2. A group of similar cells working together to carry out a particular function.
3. A structure made of several different tissues working together to carry out a function (1);
   leaf / root / stem / flower (1).
4. (a) organ; (b) organelle; (c) cell; (d) tissue; (e) organ system.
5. Stomach cells contain organelles such as mitochondria (1); similar cells form tissues such as
   muscle tissue (1); several tissues form the stomach, an organ, which works with other organs
   (oesophagus, intestines, pancreas) in the digestive system (1).

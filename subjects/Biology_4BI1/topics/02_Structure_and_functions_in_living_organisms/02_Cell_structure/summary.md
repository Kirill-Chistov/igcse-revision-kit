# Cell structure — Summary

**Specification points 2.2–2.6B** · 2.5B and 2.6B are Paper 2 only

## Structures and functions

| Structure | Function | Plant / animal |
| --- | --- | --- |
| Nucleus | contains chromosomes; controls the cell | both |
| Cytoplasm | most chemical reactions | both |
| Cell membrane | partially permeable; controls entry/exit | both |
| Mitochondria | aerobic respiration → releases energy | both |
| Ribosomes | protein synthesis | both |
| Cell wall | cellulose; support, shape, stops bursting | plant |
| Chloroplasts | chlorophyll absorbs light for photosynthesis | plant |
| Large permanent vacuole | cell sap; keeps cell firm | plant |

## Differentiation (P2)

- Unspecialised cell → specialised cell with structures for one function.
- Specialised cells do one job efficiently → tissues → organs.

## Stem cells (P2)

- Unspecialised; divide and differentiate. Embryonic: any cell type. Adult (bone marrow): limited range.
- For: replace damaged cells, treat incurable conditions; own cells not rejected.
- Against: embryo destroyed (ethics); rejection of donor cells; tumours; viral infection; adult cells limited.

## Traps

- Wall is fully permeable; membrane controls entry.
- Mitochondria release energy, not make it. Root cells have no chloroplasts.

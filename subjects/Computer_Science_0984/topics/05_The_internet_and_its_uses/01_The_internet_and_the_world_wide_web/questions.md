## Questions

1. Explain the difference between the internet and the world wide web. **[2]**
2. Tick one box per row: does each feature belong to the internet or the world wide web? **[4]**
   (a) sending and receiving email (b) a collection of web pages (c) the infrastructure of
   interconnected networks (d) resources accessed through a web browser
3. A user enters `https://www.bookshop.com/offers/today.html`. Identify: (a) the protocol, (b) the
   domain name, (c) the web page / file name. **[3]**
4. Describe the purpose and operation of HTTP. **[3]**
5. Give **two** differences between HTTP and HTTPS. **[2]**
6. State the main purpose of a web browser. **[1]**
7. Identify **three** functions of a web browser, other than its main purpose. **[3]**
8. Describe how a web page is located, retrieved and displayed when a user types a URL into a
   browser. Include the role of the DNS, IP addresses, the web server and HTML. **[6]**
9. Explain what is meant by a cookie. **[2]**
10. Describe **two** differences between session cookies and persistent cookies. **[4]**
11. An online shop uses cookies. Describe **three** ways the shop could use them. **[3]**

## Marking guidance

1. Internet: the infrastructure / worldwide collection of interconnected networks and devices (1).
   WWW: the collection of websites / web pages accessed using the internet (1).
2. (a) internet (b) WWW (c) internet (d) WWW — 1 each.
3. (a) `https` (b) `www.bookshop.com` (c) `/offers/today.html` (or `today.html`) — 1 each.
4. Any three: a set of rules / protocol (1) for transferring web pages / files between browser and
   web server (1); browser sends a request for a resource (1); server sends a response containing
   the file / HTML, or an error (1).
5. Any two: HTTPS encrypts data, HTTP does not (1); HTTPS uses SSL (1); HTTPS authenticates the web
   server with a certificate (1); HTTPS shows `https` / padlock (1).
6. To render HTML and display web pages (1).
7. Any three: address bar; navigation tools (back/forward/refresh); multiple tabs; storing
   bookmarks/favourites; recording user history; storing cookies.
8. One mark per point, max 6: URL typed into the address bar; browser sends domain name to the DNS;
   DNS searches its database of domain names and IP addresses; if not found the request is passed to
   another DNS; the IP address of the web server is returned to the browser; browser sends an HTTP
   request to the web server using the IP address; web server sends the page as HTML; browser renders
   the HTML and displays the page.
9. A small file sent by a web server (1) and stored by the browser on the user's device, holding
   data about the user / visit that is sent back on later visits (1).
10. Any two pairs (2 each): session stored in temporary memory / RAM, persistent stored on the
    device's storage; session deleted when the browser closes, persistent kept until expiry date or
    deleted by user; session does not remember the user between visits, persistent does.
11. Any three: holding items in the shopping cart; storing login details; saving personal details
    (e.g. address); tracking user preferences / targeted adverts.

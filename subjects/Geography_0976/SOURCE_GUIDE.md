# Geography 0976 — Source Guide

Subject-specific application of `rules/SOURCE_POLICY.md`. Short on purpose.

## Authority order

1. **Cambridge IGCSE (9–1) Geography 0976 syllabus, 2027–2029** —
   `subjects/Geography_0976/Specification.pdf`. Absolute authority on scope. Nothing overrides
   it. `specification.md` is an index into it, not a substitute.
2. **The student's own class sources** — the primary authority for centre-chosen detailed specific
   examples: class notes, a school case-study document, photographed textbook pages. Kept in
   `me/sources/Geography_0976/` (not in Git — they belong to the school or publisher).
3. **Sources the student supplies later** (photos, screenshots) — save them to the same folder
   and record the example in `me/profile.md` before use.
4. **Targeted web research** — permitted only for ordinary required geography (processes,
   definitions, global patterns, models, accurate map/diagram detail), and only where it genuinely
   improves a required explanation. It must never expand scope.
5. **Web and model knowledge must never supply or replace a centre-chosen detailed example** —
   not a name, a date, a statistic, an impact, a response or an evaluation point. Silence plus a
   placeholder is correct; a plausible substitute is not.

Official Cambridge assessment material (mark schemes, examiner reports, specimen papers), when
present in `me/papers/Geography_0976/`, ranks directly below the syllabus for
*how* answers are rewarded.

## Case studies in the shipped notes

The notes in this repository use one class's examples (listed in `CASE_STUDY_TRACKER.md`): Haiti
earthquake 2010 · Eyjafjallajökull 2010 · USA Eastern Seaboard · Great Barrier Reef · Vietnam
(development) · Nairobi River pollution · Mongolia / Rio Tinto · Nigeria food insecurity · Sweden
energy. A student whose school uses other examples rewrites those blocks from their own sources.

## Rules

- Use what the source actually says. Record only supported detail; leave gaps as gaps.
- Do not correct the class source silently. If a figure or statement looks wrong, flag it in
  `CASE_STUDY_TRACKER.md` and ask the student.
- Do not add outside detail to a class case study unless the student explicitly asks for research.
- Check the code before using anything found online: **0976**, 2027–2029 — not 0460, and not the
  2025–2026 version of 0976. Topic content differs.
- Synthesise; do not paste long passages from any source.
- "The source does not say" is an acceptable and useful answer.

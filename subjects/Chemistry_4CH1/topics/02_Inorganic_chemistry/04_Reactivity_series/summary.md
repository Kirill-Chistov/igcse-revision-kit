# Reactivity series — Summary

Specification points 2.15–2.21 · Topic 2 Inorganic chemistry.

## Order (most → least reactive)

**K, Na, Li, Ca, Mg, Al, Zn, Fe, (H), Cu, Ag, Au**

## Essential facts

- Cold water (K–Ca): metal hydroxide + H₂. Steam (Mg, Zn, Fe): metal oxide + H₂.
  Dilute acid (above H): salt + H₂. Cu, Ag, Au: no reaction.
- Al looks unreactive: protective **oxide layer**.
- Practical: same acid volume, concentration, temperature; same-size metal pieces; compare
  bubbling and temperature rise; lighted splint → pop. **Mg > Zn > Fe**; Cu none.
  Fe + 2HCl → FeCl₂ + H₂; Mg + H₂SO₄ → MgSO₄ + H₂.
- **Displacement**: more reactive metal displaces less reactive from oxide (Mg + CuO → MgO + Cu;
  2Al + Fe₂O₃ → Al₂O₃ + 2Fe) or salt solution (Zn + CuSO₄ → ZnSO₄ + Cu: blue fades, pink-brown
  solid, warms). Order = number of metals each displaces.
- Rust = hydrated iron(III) oxide; needs **water AND oxygen**.
- Prevention: **barrier** (paint, oil, plastic — keeps out water/O₂); **galvanising** (zinc coat:
  barrier + sacrificial); **sacrificial** (Zn/Mg blocks lose electrons instead of iron).

## Definitions

| Term | Definition |
| --- | --- |
| Oxidation | gain of oxygen / loss of electrons |
| Reduction | loss of oxygen / gain of electrons |
| Redox | oxidation and reduction together |
| Oxidising agent | oxidises another substance; is itself reduced |
| Reducing agent | reduces another substance; is itself oxidised |

Zn + Cu²⁺ → Zn²⁺ + Cu: Zn oxidised (reducing agent), Cu²⁺ reduced (oxidising agent).

## Common traps

- Oxidising agent is **reduced**. Copper does **not** react with dilute acids.

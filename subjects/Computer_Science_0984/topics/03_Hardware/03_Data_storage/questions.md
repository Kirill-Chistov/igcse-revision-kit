## Answers and marking guidance (not official)

1. Storage that is directly accessed by the CPU (e.g. RAM, ROM).
2. Any two: RAM volatile / ROM non-volatile; RAM read and write / ROM read only; RAM holds data and
   programs in use / ROM holds start-up instructions.
3. HDD; CD/DVD/Blu-ray; SSD/SD card/USB drive.
4. RAM holds the data/programs currently in use and can be changed (1); RAM is volatile, so it is
   empty when the computer is turned on (1); the start-up/boot instructions must be kept in ROM,
   which is non-volatile and cannot be changed (1).
5. Laser shone onto the spiral track (1); lands reflect light back to a sensor (1); pits scatter
   the light; the pattern is converted to binary (1).
6. Uses transistors arranged as NAND/NOR flash (1); each has a control gate and a floating gate (1);
   electrons are forced into/trapped in the floating gate by the insulating layer (1); charged or
   not charged represents 1 or 0, kept without power (1).
7. RAM is full (1); OS uses part of the HDD/SSD as virtual memory (1); pages not currently needed
   are moved from RAM to virtual memory and moved back when needed (1); virtual memory is much
   slower to access than RAM / swapping takes time (1).
8. No moving parts, so less likely to be damaged if knocked (1); faster access / lighter / uses
   less power (1).
9. Platters spin; surface divided into tracks and sectors (1); read/write head moves to the track
   (1); head is an electromagnet that magnetises tiny areas in one of two directions to write 1/0
   (1); reads by detecting the direction of magnetisation (1).
10. Explained points, max 3 per side. Advantages: staff can access files anywhere with internet;
    no need to buy/maintain own storage hardware; storage can be increased easily; provider backs
    up data. Disadvantages: needs reliable internet / slow for large files; data held by a third
    party — security/privacy risk; subscription cost; provider outage or closure could make data
    unavailable.

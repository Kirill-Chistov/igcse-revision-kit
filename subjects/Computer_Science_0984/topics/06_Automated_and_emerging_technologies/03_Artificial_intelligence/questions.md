## Questions

1. State what is meant by artificial intelligence (AI). **[2]**
2. Describe the main characteristics of AI. **[3]**
3. Identify the **four** components of an expert system. **[4]**
4. Describe the role of the inference engine in an expert system. **[3]**
5. State the difference between the knowledge base and the rule base. **[2]**
6. A garage uses an expert system to find faults in cars. Explain how the expert system works to
   find a fault. **[5]**
7. State what is meant by machine learning. **[2]**
8. An email service uses machine learning to filter spam. Explain how machine learning allows
   the filter to improve over time. **[4]**
9. Explain why an expert system shows some characteristics of AI but not the ability to learn and
   adapt. **[3]**

## Marking guidance

1. A branch of computer science (1) dealing with the simulation of intelligent behaviours by
   computers (1).
2. A collection of data and the rules for using that data (1); the ability to reason / draw
   conclusions from the data (1); it can include the ability to learn and adapt (1).
3. Knowledge base (1); rule base (1); inference engine (1); interface (1).
4. One mark per point, max 3: applies the rules in the rule base to the facts in the knowledge base;
   uses the user's answers; decides / chooses the next question based on previous answers;
   reaches a conclusion / diagnosis.
5. Knowledge base stores the facts about the specialist area (1); rule base stores the (IF…THEN)
   rules used to reason with those facts (1).
6. One mark per point, max 5: interface asks the mechanic questions (e.g. yes/no) about the
   symptoms; mechanic enters answers through the interface; inference engine applies rules from
   the rule base to the answers and the facts in the knowledge base; next question chosen based
   on previous answers; process repeats until a match is found; interface displays the likely
   fault / suggested repair, with its probability and reasons.
7. A program has the ability (1) to automatically adapt its own processes and/or data (1).
8. One mark per point, max 4: trained with a large amount of example emails labelled spam / not
   spam; finds patterns (e.g. words, senders) common in spam; uses them to decide whether a new
   email is spam; feedback, e.g. the user marks a missed spam email; the program adapts its own
   processes / data (updates its patterns) automatically, without being reprogrammed.
9. It has a collection of data (knowledge base) and rules (rule base) (1); it can reason / draw
   conclusions using the inference engine (1); it cannot change its own rules or facts —
   people must update the knowledge base / rule base (1).

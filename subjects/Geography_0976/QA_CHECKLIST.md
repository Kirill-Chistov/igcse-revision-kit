# Geography — QA Checklist

Run this against any study material before treating it as finished.

## Specification

- [ ] The material names the exact specification points it covers, by official number.
- [ ] Every mapped requirement **and every sub-bullet of it** is actually covered — nothing
      quietly dropped.
- [ ] Nothing off-specification is presented as required content.
- [ ] Paper, tier and other course distinctions in `SUBJECT_RULES.md` are respected.

## Detailed specific examples

- [ ] Every required detailed specific example either rests on a confirmed class source or carries
      the explicit missing-source placeholder — in `topic.md`, `summary.md` **and** `questions.md`.
- [ ] No case-study fact is invented: every name, date, figure, impact, response, outcome and
      evaluation point traces to `me/sources/Geography_0976/`.
- [ ] No web or model detail has been added to, or substituted for, a class example.
- [ ] `CASE_STUDY_TRACKER.md` matches what was actually written, and every source gap is reported
      to the student with the spec point and the kind of source needed.

## Correctness

- [ ] Every factual claim, equation, figure and unit is correct.
- [ ] Terminology matches the awarding body's own usage.
- [ ] Definitions are precise enough to earn the mark.

## Usability

- [ ] Understandable by a Year 11 student who has covered the earlier specification points.
- [ ] Difficult ideas are explained, not merely named.
- [ ] Examples and diagrams clarify rather than pad.
- [ ] Every visual is geographically accurate, labelled in the syllabus's own terms, and renders
      correctly in the topic PDF.
- [ ] No enrichment (Level C) — only required content plus minimal bridging.
- [ ] No filler, repetition or textbook throat-clearing; the same idea is not taught as prose *and*
      table *and* diagram.

## Consistency

- [ ] Consistent with other material already in `Geography_0976/` for this subject.
- [ ] Follows `subjects/Geography_0976/CONTENT_STYLE.md` and `rules/STYLE_GUIDE.md`.
- [ ] Sources used respect `subjects/Geography_0976/SOURCE_GUIDE.md` and `rules/SOURCE_POLICY.md`.

## Repository hygiene

- [ ] Markdown is the canonical version; the topic PDF was rebuilt from it and visually checked.
- [ ] No recap, self-test, answers or checklist sections in `topic.md`, `summary.md` or the PDF.
- [ ] `coverage_checklist.md` and `specification_map.csv` rows for the covered points updated.

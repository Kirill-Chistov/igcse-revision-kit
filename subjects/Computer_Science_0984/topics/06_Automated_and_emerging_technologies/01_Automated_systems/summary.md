# 6.1 Automated systems — summary

Cambridge IGCSE (9–1) Computer Science 0984 · points 6.1.1–6.1.2 · Paper 1

## How it works

- **Automated system** — hardware (sensors, microprocessor, actuators) + software doing a task with
  no human intervention.
- Loop: **sensor** reads → **ADC** if analogue → **microprocessor compares** with **stored** values →
  outside range: **signal to actuator** (inside: no action) → **actuator** moves motor / valve /
  pump / switch → process changes → **repeats continuously**.
- Always use the scenario's own sensor and actuator names.

## Advantages / disadvantages (word them for the scenario)

- **+** faster response · safer (people away from danger) · 24/7 · consistent, optimum conditions,
  less waste · lower long-term staff costs.
- **−** expensive set-up and maintenance · fails in unprogrammed situations or with a faulty sensor ·
  hacking · job losses, over-reliance.

## Scenarios

- **Industry** — temperature/pressure/flow/gas → valves, pumps, shut-down.
- **Transport** — proximity sensors → brakes/throttle (adaptive cruise control).
- **Agriculture** — moisture/level → water pumps; saves water.
- **Weather** — temperature, humidity, pressure, light, level; stores and transmits; remote, 24/7.
- **Gaming** — accelerometer, proximity → vibration motor; immersive.
- **Lighting** — light + infra-red → lights on/off/dim; saves energy.
- **Science** — level/pH/temperature/light → tap or valve; repeatable, safe.

## Traps

- Sensors don't decide; microprocessors don't move things.

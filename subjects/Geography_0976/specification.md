## Course distinctions that affect what can be assessed

- **Detailed specific examples are chosen by the centre**, not named in the syllabus. Some
  questions require named examples; the student's own are recorded
  in `me/profile.md` (see `CASE_STUDY_TRACKER.md`). Cambridge recommends examples from CE 2000–present.
- Impacts are always considered as positive/negative, social/economic/environmental, and at
  local/regional/national/global scales. Sustainability runs through every topic.
- Resource-based questions (maps, photographs, graphs, statistics) appear in all written papers;
  units are metres/kilometres, degrees Celsius and millimetres.
- **Geographical Skills** (including map and Ordnance-Survey-style skills) are assessed across
  the papers and are treated here as a content area in their own right.


## How to read this file

- This file is a **curriculum representation**, not revision notes. It exists so that AI
  agents can plan and trace study material without re-parsing the official PDF.
- Official identifiers (section numbers, specification point numbers, topic names) are
  preserved so every statement can be traced back to `subjects/Geography_0976/Specification.pdf`.
- Requirement wording is condensed/paraphrased from the official objective statements.
  **The official PDF is always authoritative** where this file is ambiguous.
- `specification_map.csv` maps each specification point to its planned folder in `Geography_0976/`.
- `coverage_checklist.md` tracks which points have study material written.

# Geography 0976 — Detailed Specific Example Tracker

**Cambridge IGCSE (9–1) Geography (0976), 2027–2029.**
Sixteen specification points require a **detailed specific example** (case study). Cambridge does
**not** name them — each school chooses its own (syllabus p.12). Read this before generating or
teaching any topic that contains one.

## What the shipped notes use

The notes in this repository were written for one class. Where that class had an example, the notes
teach it; where it did not, the notes carry a placeholder. **Your school may use different
examples.** In an exam you can only write detail you have actually learned, so:

- if your school uses the **same** example → use the notes as they are;
- if your school uses a **different** one → record it in `me/profile.md` (Geography case studies),
  put your class notes or textbook pages in `me/sources/Geography_0976/`, and run `/make-topic` on
  that subtopic: the case-study block is rewritten from your sources (in your own copy);
- if the notes show the placeholder → same as above; nothing is invented to fill it.

## Rules for writing a case study

- Write it **only** from the student's own sources (`me/sources/Geography_0976/`: class notes,
  textbook pages they photographed, a school case-study document) — not from the web or model
  knowledge. A plausible substitute is worse than the placeholder.
- Web research may complete a missing sub-bullet **only when the student explicitly asks**, and the
  researched part stays visibly attributed so they know it did not come from lessons.
- Do not correct a class source silently: if a figure looks wrong, say so and ask.
- After writing one, update this row (in the student's copy) and rebuild the topic PDF.
